minitelnet
**********

**minitelnet** is a small, allocation-free Telnet protocol engine
for C. It provides streaming Telnet parsing, command encoding,
RFC 1143 option negotiation, and subnegotiation handling.

The library is transport-independent and does not perform network
I/O or implement the semantics of individual Telnet options.
